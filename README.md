# 💰 Crypto Wallet

A full-stack digital wallet application built with Next.js, Spring Boot, and PostgreSQL.

## 🚀 Features

- User Signup & Login
- JWT Authentication
- Wallet Balance
- Deposit
- Withdraw
- Send Funds
- Receive Funds
- Transaction History
- User Profile
- Responsive UI

## 🛠️ Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Java
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate

### Database
- PostgreSQL

## ⚠️ Disclaimer

This project is a demo digital wallet application created for learning and portfolio purposes.

It does not perform real cryptocurrency transactions on a blockchain.
